# Ace Group of Companies — Website

A multi-page marketing site for Ace Group of Companies, built with React, React Router, and Vite.

## Pages

- `/` — Home
- `/services/:id` — Division detail (Education, Software, AI & Automation, eHailing, EdTech)
- `/events` — Bootcamp / events
- `/education-products` — Education products overview
- `/tutoring` — Private tutoring plans
- `/software-products` — Software development services
- `/privacy`, `/terms`, `/refund`, `/delivery` — Legal pages

## Getting started

```bash
npm install
npm run dev
```

Then open the printed local URL (usually http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```
